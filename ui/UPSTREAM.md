# Upstream provenance

This is the existing datarhei/restreamer-ui React application, imported from
https://github.com/datarhei/restreamer-ui at commit
7164b38cb3a8655f7cd896e941093a1ca166b19b (UI 1.14.0 / Restreamer 2.12.0).

The Apache-2.0 license is retained in LICENSE. Woody adds Studio and Chatbot views,
a same-origin API client, and navigation entries. Existing channel, publication,
player, configuration, translation, and authentication code remains upstream code.

To update, compare against this commit and merge upstream changes into ui/;
do not replace this directory with a generated build.
